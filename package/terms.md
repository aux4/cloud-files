# Cloud Files usage terms

Draft for the proposed usage-based plan.

## Billing and storage

The scope owner accepts the plan for the scope. The scope shares one storage allowance across users, virtual machines and shared files. The usage view attributes stored bytes to each owner so the scope can investigate its total.

The scope shares 1 GB of included storage. Storage above this allowance costs USD $0.10 per decimal GB-month, prorated by the time each byte is stored. One decimal GB is 1,000,000,000 bytes. Billable usage is the amount above the shared allowance multiplied by how long it is stored. An overwrite changes usage by the difference in size. A deletion stops future storage accrual for the deleted bytes. The invoice rounds the scope's storage charge once per billing period.

Usage billing starts at the effective time shown to the scope owner, after acceptance and verification of the scope's opening storage balance. Existing files count toward usage from that time. Earlier storage time is excluded.

## Changes to the plan

The scope owner can review the package version, price, allowance and applicable terms before accepting. Changes to the price or these terms require a new acceptance before they apply to the scope.
