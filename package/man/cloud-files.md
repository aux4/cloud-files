# cloud-files

Manage per-user files stored by aux4 Cloud applications.

The selected scope owns the plan policy. Usage and limits are enforced independently for each authenticated user.

aux4 Cloud includes 1 GiB per user. Paid Small, Medium, and Large tiers provide 10, 50, and 100 GiB per user respectively. A paid tier replaces the included allowance; storage does not stack.

## Commands

- `list` — list files in a VM's user folder
- `get` — read a text file
- `upload` — upload or replace a file
- `delete` — delete a file
